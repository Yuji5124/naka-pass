# NAKA PASS

**いつもの店、これだけ。** 自分専用の買い物・ポイント運用メモです。最大還元ではなく「判断ゼロ運用」を目指し、レジ前で出すカードと支払い方法を固定します。

## 起動方法

HTML / CSS / Vanilla JavaScriptのみで動作します。ログイン・API・Firebase・依存パッケージは不要です。

Pythonがある場合、リポジトリのフォルダで次を実行してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終了は Ctrl+C。PWAはHTTPSまたはlocalhostで動作します。ファイルを直接開く方法ではService Workerは動作しません。

## GitHub Pagesで公開

1. このフォルダのファイル一式をGitHubの `Yuji5124/naka-pass` の `main` ブランチへコミット・プッシュします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment → Source** に **Deploy from a branch** を選択します。
4. Branchを **main**、フォルダを **/ (root)** にして **Save** を押します。
5. デプロイ完了後、Pages画面に表示されるURLを開きます。通常は `https://yuji5124.github.io/naka-pass/` です。

相対パスを使用しているため、GitHub Pagesのサブディレクトリでも動作します。公開操作はこの実装には含まれません。

## iPhoneのホーム画面に追加

1. GitHub Pagesで公開したURLを **iPhoneのSafari** で開きます。
2. ページの読み込みが完了してから、Safariの **共有** ボタンを押します。
3. **ホーム画面に追加** を選びます。見つからない場合は共有メニューを下にスクロールします。
4. 名前「NAKA PASS」を確認して **追加** を押します。
5. ホーム画面のアイコンから開きます。ブラウザの枠なしで使用できます。

AndroidではChromeのメニューからインストール／ホーム画面に追加できます。一度読み込むと画面と保存済み設定はオフラインでも利用できます。公式サイト・外部アプリの通信にはネット接続が必要です。

## 使い方・設定

- **ホーム**：まいばすけっと → セブン → ローソン → イトーヨーカドー → マツキヨの固定順。今いる店舗の「○○を開く」を押します。
- **カード**：7種類の登録済み／未登録を切り替えます。初期値は未登録（未入力）です。登録状態は個人用メモであり、公式アプリへの登録・連携は行いません。ホームの固定ルールも変更しません。
- **設定**：店舗ごとの支払い方法とURLを入力して「設定を保存」を押します。支払い方法はホームに反映されます。

設定はLocalStorage（`naka-pass.v1`）へ保存します。この端末・ブラウザ・サイト内のみで有効です。データ削除やプライベートブラウズでは保持されない場合があります。サーバー同期やバックアップはありません。保存に失敗した場合は画面に案内します。

### 公式アプリのリンク

初期値は各ブランドの公式Webトップページです。今回の環境では公式サイトへの調査アクセスがネットワーク制限で遮断され、5アプリの公式なURL Scheme / Universal Linkを確認できなかったため、推測したアプリ起動URLは実装していません。Webから公式アプリの案内を探してください。リンク先の現在の内容・到達性もこの環境では検証できていません。

公式に確認したHTTPSリンク、またはアプリのURL Schemeを持っている場合は設定で変更できます。危険な `javascript:` / `data:` 等は受け付けません。外部リンクは別の画面に開き、NAKA PASSを保持します。アプリ未インストール時の挙動はOSによって異なり、任意のURL Schemeの起動成否はWeb側から確実には判定できません。その場合は設定を公式Web URLに戻してください。

## ファイル構成

```text
index.html       画面とiOS用メタ情報
style.css        スマートフォン優先のデザイン
app.js           店舗表示・タブ・設定保存
manifest.json    PWA設定
sw.js            オフライン用キャッシュ
icons/           オリジナルPNGアイコン
README.md        この説明
```

画面に外部フォントやライブラリは使用していません。配信ファイルを更新する場合は `sw.js` の `CACHE` のバージョンも変更してください。新しいService Workerは既存の画面をすべて閉じた後に有効になります。

## 検証と制限

モバイル幅320px・390pxとデスクトップ表示、店舗順・ポイント表示、登録状態と支払い設定の再読み込み、URL検証、GitHub Pages相当のサブパス、Service Worker経由のオフライン再読み込みをChromiumの自動ブラウザで確認済みです。ブラウザエラーもありませんでした。iPhone実機でのホーム画面追加や外部アプリ起動は別途実機確認が必要です。
